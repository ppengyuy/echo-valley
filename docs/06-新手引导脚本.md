# 06 新手引导脚本

> 给人第一次打开网页时用的九步导览。每一步的文案、聚光位置、进入时先把界面切到哪一屏，都在这里；改文案只改 `src/App.tsx` 里的 `tourSteps`，改聚光位置只改 `target`。
> 步骤里的每个功能，与 [05-页面与交互清单.md](./05-页面与交互清单.md) 的条目一一对应，本文最后一列标了出处。

## 触发与收尾

| 时机 | 行为 |
|---|---|
| 首次打开、且已点过首启知情弹窗 | 700ms 后自动出现第 1 步 |
| 点「先不看」、`Esc`、走完点「开始体验」 | 关闭并写 `echo-valley:tour-seen=1`，之后不再自动弹；关闭后回到回音谷·倾诉 |
| 设置 →「再看一遍新手引导」 | 先收起设置，再从第 1 步重放（不清除已看标记） |
| 键盘 | `←` / `→` 切换，`Esc` 退出 |

实现：`src/components/TourGuide.tsx`（一层不挡点击的暗层 + 四块挖洞 + 聚光描边 + 一张卡片），样式在 `styles.css` 末尾「新手引导」块，≤560px 时卡片贴底（让开底部 Tab）。

## 九步

| # | 标题 | 聚光目标 | 正文要点 | 对应 05 |
|---|---|---|---|---|
| 1 | 这是回音谷，先花一分钟认一下 | 无（居中/贴底卡片） | 三个空间各管什么；不做心理咨询、不解题 | §2、§3 |
| 2 | 三条入口，挑最轻的那一条 | `.entry-nav` | 倾诉 / 梳理行程 / 聆听回音 | §3 |
| 3 | 想说话，就写在这里 | `.composer` | `Enter` 发送、`Shift+Enter` 换行；「只想留一句话，不用回应」 | §3、§4 |
| 4 | 不想开口，也有别的入口 | `.quiet-chip` | 「今天不想说话」→ 坐一会儿 / 听声音 / 借一句话 | §4 |
| 5 | 山间小路：把想推进的事排进这一周 | `.path-panel .panel-head` | 「重新标一遍」走向导；卡片可拖到别的日子 | §9、§10 |
| 6 | 静一下心：九个练习，随手挑一个 | `.calm-panel .calm-head` | 呼吸、身体扫描、舒尔特……都写明时长和「做到哪里就可以停」 | §11 |
| 7 | 留下来的句子，都在这儿 | `.echo-view .echo-toolbar` | 搜索、置顶（最多 3 条）、归档、消散；不确认就不留 | §5 |
| 8 | 最后，看一眼「设置」 | `.quiet-tools` | 存储方式、JSON 备份、清空山谷、重看引导 | §16 |
| 9 | 从哪一步开始都行 | 无 | 从哪一步开始都不影响，准备好了就开始 | — |

第 1、5、6、7、8 步带 `enter()`：先把界面切到该出现的样子（切 Tab / 切到山间小路 / 切到静一下心 / 切回回音谷的「聆听回音」），再找目标位置；找不到目标（例如宽屏下某个面板没渲染）就退回居中的卡片，不会空着。

## 写文案的口气

- 一句一件事，不超过三行；不给「必须」「应该」，不用感叹号。
- 每步最多一句小提示（`hint`），用左侧细线标出，不抢正文。
- 只描述入口「在哪、点了会怎样」，不承诺效果，不催进度。

## 复检清单

1. 清掉 `localStorage` 里的 `echo-valley:tour-seen`，刷新首页 → 应自动出现在第 1 步；
2. 一路 `→` 到第 9 步，聚光依次落在入口条、输入框、静默芯片、山间小路标题行、静一下心标题、回音工具条、设置；
3. 点「开始体验」→ 引导消失、回到回音谷；再刷新 → 不再自动弹；
4. 设置里点「再看一遍新手引导」→ 设置收起、引导从第 1 步重放；
5. ≤560px（手机）时卡片贴底、不压住底部三个 Tab；聚光不遮挡卡片正文。
