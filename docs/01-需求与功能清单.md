# 01 需求与功能清单

> 回音谷：面向备考学生的 AI 情绪陪伴产品。AI 角色「刘看山」陪用户倾诉情绪、记录感悟、闲聊、商量学习计划，复盘时看见自己的变化。
> 来源：知乎黑客松 S3「AI·陪伴与交互」赛道。技术栈：Vue3 + FastAPI + SQLite + OpenAI 兼容 LLM。

## 1. 设计原则

1. **双空间隔离**：回音谷（valley：情绪/感悟/闲聊）与山间小路（path：目标/计划/任务）互不越界。
2. **掌控权归用户**：存不存、删不删、看不看由用户决定，AI 只询问、不擅自动作。
3. **克制不打扰**：不推送、不弹窗、无积分勋章、无打卡红点。
4. **接纳不评判**：不灌鸡汤，接纳疲惫、摆烂、害怕；先接住感受再谈其他。

## 2. 功能清单

优先级：P0 = MVP 必须；P1 = 首版尽量有；P2 = 增强。

| 模块 | 功能 | 优先级 | 说明 |
|---|---|---|---|
| F1 账号 | 注册 / 登录 | P0 | 用户名 + 密码，JWT |
| F1 账号 | 个人资料与记忆管理 | P1 | 只记录用户亲口告知的信息，可逐条查看、删除 |
| F2 对话 | 双空间会话 | P0 | valley / path 上下文互相隔离 |
| F2 对话 | 闲聊与倾诉 | P0 | 无目的闲聊顺话题倾听；倾诉时先接住感受，不给建议、不喊加油 |
| F2 对话 | 语义存档询问 | P0 | 命中 4 类内心表达（主观情绪抒发 / 自我反思 / 阅读触动 / 心结·期许·信条）时询问"要不要存入山谷？"；普通吐槽、事实陈述、提问不触发 |
| F2 对话 | 决定存档 | P0 | 同意 → 原话存为回音；拒绝 → 不留任何记录 |
| F2 对话 | 手动强制保存 | P0 | 用户说"把这句话存为回音"，跳过询问直接保存 |
| F2 对话 | 复盘唤起旧回音 | P0 | 复盘对话中以纯文本引用旧回音原话 + 开放式提问；不对比、不下结论；用户转移话题即不再提 |
| F2 对话 | 安全兜底 | P0 | 检出伤害自己的念头 → 停止深挖情绪，转介学校心理中心 / 专业援助 |
| F2 对话 | 边界拒答 | P0 | 搜题解题 → 拒绝；心理诊疗 → 转介；话题始终围绕备考心境、阅读感悟、学习生活 |
| F2 对话 | 停止对话 | P0 | "我想自己待一会" → 立即停下，不追问不硬续 |
| F3 回音 | 波纹陈列视图 | P0 | 独立入口；每条回音 = 一圈波纹；触碰弹出原话 + 时间戳（不改写、不摘要、不贴标签） |
| F3 回音 | 归档 / 恢复 | P0/P1 | 归档进入分组、可回看；恢复为 P1 |
| F3 回音 | 消散（删除）/ 一键清空 | P0 | 物理删除、不可恢复，删除前二次确认 |
| F3 回音 | 空状态 | P0 | "山谷还没有收到你的回音，你的感受、触动、疑惑，都可以安心留在这。" |
| F3 回音 | 五次彩蛋 | P1 | 累计保存 5 条 → 一行淡色文字飘过："你已经五次愿意停下来，听见自己。"无弹窗无奖励 |
| F3 回音 | 关联连线 | P1 | 相关回音间极淡微光连线，仅陈列视图可见，对话框不展示 |
| F4 镜像回音 | 触发与引导 | P0 | 持续自我否定时不硬安慰，问"要不要开启镜像回音？"；引导用户以好友视角写下安慰自己的话 |
| F4 镜像回音 | 强制询问与退出 | P0 | 写完强制询问是否保存（同意/拒绝仍由用户定）；随时退出，立即回普通聊天 |
| F5 计划 | 向导式收集 | P0 | 逐步问 4 组：最终目标 / 截止时间 / 每日真实可用时长 / 个人节奏（专注时长、休息缓冲、怕不怕排满） |
| F5 计划 | 拆解与超载删减 | P0 | 年→月→周→日；排不下主动删减并告知删了什么；每周留一天缓冲日，允许被打乱 |
| F5 计划 | 可视化与导出 | P0 | 山巅=大目标、节点=阶段任务、脚印=每日任务；一键导出 Excel / CSV，可打印 |
| F5 计划 | 不催打卡 | P0 | 不推送不催促；用户主动回来时可标记任务完成/跳过；大量未完成也不指责 |
| F6 复盘 | 双线并排 | P0 | 仅用户主动触发；并排展示任务脚印 × 回音，不做 AI 解读 |
| F8 视觉 | 欢迎语与氛围 | P0 | 首次欢迎语 + 三入口（倾诉 / 规划 / 听回音），也可不点直接聊；雾绿山谷、刘看山剪影，无弹窗红点 |

## 3. 红线（绝对不做）

| 编号 | 红线 | 实现约束 |
|---|---|---|
| R1 | 不搜题、解题、讲知识点 | 系统 Prompt 硬规则 + 意图拦截 |
| R2 | 不做心理咨询、不诊断；危险念头转介专业援助 | 安全兜底优先于一切生成 |
| R3 | 不偷存：闲聊不自动存回音，保存必须本人同意，可随时删 | 回音只有确认 / 手动指令两条写入路径 |
| R4 | 不主动发消息、不推送 | 无推送通道、无定时提醒 |
| R5 | 不灌鸡汤 | Prompt 风格约束 |
| R6 | 不拿旧回音批评用户 | 复盘只念原话 + 开放提问 |
| R7 | 不贴标签，只记亲口说的信息 | 无标签字段；记忆只收显式陈述 |
| R8 | 无积分、勋章、排行榜 | 无相关字段与组件 |
| R9 | 闲聊不无限发散 | 话题边界 + 拉回话术 |

## 4. 非功能

- 流式对话首 token ≤ 3s；LLM 不可用时保留用户输入并明确报错。
- 删除即物理删除；拒绝保存的内容不落库、不进记忆。
- 密码 bcrypt；JWT 有效期 7 天；移动端可用（响应式）。
