# 04 · 部署到知乎 AI Works（面向开发者）

> 适用场景：本地已能运行、**不依赖独立数据库**的前端 / 轻量全栈项目，发布到知乎 AI Works 并取得一个可分享的访问链接。
>
> 本项目（回音谷）符合这个前提：数据存在浏览器会话里（sessionStorage），不接任何外部数据库。后端 FastAPI 目录是为完整部署准备的，**AI Works 一键部署只需前端部分**。

---

## ⚠️ 先读这一段：密钥安全铁律

**贯穿下面所有步骤，任何一步都不得违反：**

1. **只引导用户自己在本地填写 API Key**。你（无论是 Agent 还是部署者）**不得索要、不得记录、不得展示**用户的密钥。
2. **不得把密钥写进源码、仓库或上传包**。不要 `console.log` 密钥，不要拼进 URL，不要写进 `.env` 一并上传，更不要提交到 Git。
3. **CLI / 平台若提示「注入环境变量密钥」，只指导用户在自己本地配置**，不要替用户填、不要回显、不要把值贴到对话里。
4. **打包 / 上传前必须复核**：敏感信息没有进入上传包。本项目已把 `.env`、`.env.*`、`.workbuddy/` 等写入 `.gitignore`，打包时也要按同样规则排除。
5. 本项目在界面里提供的「接入模型」入口，密钥**只存当前页面内存**，刷新即清；不写浏览器存储、不上传、不进代码与包。Agent 不得读取或导出这个 Key。

一句话：**Key 属于用户，只经过用户自己的浏览器，直连模型服务商，不经任何中间方。**

## 一、发布步骤

### 1）登录项目广场，创建作品

打开 <https://www.zhihu.com/project-square>，登录知乎账号，点击「创建项目」，填写项目名称、一句话简介、项目类型、版本与说明。中途可以存草稿。

### 2）选择「源码发布」，让本地 Agent 确认构建

在项目内容一步选择**源码发布**。复制平台给出的提示词，发给你的本地 Agent，让它在项目根目录执行页面给出的命令，**先在本地确认能构建成功**（本项目对应 `npm run build`）。

> 本地构建通过再上传，能省掉绝大多数「云端构建失败」的往返。

### 3）上传生成的 ZIP

把本地确认过的工程打成 ZIP 上传。若找不到生成的文件，让 Agent 帮你拷贝到桌面再上传。

打包时注意（对应上面的安全铁律）：

- 包含：`index.html`、`package.json`、`package-lock.json`、`vite.config.ts`、`tsconfig.json`、`src/`、`public/`、必要的文档与示例配置 `.env.example`。
- **排除**：`.env`（真实密钥）、`node_modules/`、`dist/`、`.git/`、`.workbuddy/`、`.box-agent*/`、`*.genie`、后端 `backend/data/` 下的数据库文件。

### 4）观察构建状态，失败就交回 Agent 修

平台会依次经历上传、构建中、构建完成 / 失败。**构建失败时，把平台给出的完整报错（错误码 + 日志摘要）原样交给本地 Agent 修复**，改完重新上传即可。不要自己猜原因改配置。

常见坑（本项目已处理）：

- 服务必须监听 `0.0.0.0` 且使用平台指定端口，不能写死 `127.0.0.1:5178`。
- 依赖声明要完整：本项目用 npm，`package.json` + `package-lock.json` 都在。

### 5）没有独立数据库：用文件 / 浏览器存储代替

**平台暂不提供独立托管的数据库服务。** 需要持久化的地方请改为：

- 本项目现状：会话数据用浏览器 `sessionStorage`（键 `echo-valley-session-v1`），关闭页面即散，符合平台能力，无需改造。
- 若确需落盘的结构化数据：用 JSON 数据文件随工程一起打包读取，或改用平台提供的托管能力。**不要依赖运行时写入容器本地的 SQLite 文件**——容器重启后文件会丢失。

> `backend/` 目录里的 FastAPI + SQLite 是给「自己部署完整前后端」用的，不在 AI Works 一键部署范围内，上传时可以不含它。

### 6）预览链接 ≠ 正式链接

- 带 `preview` 的预览链接**只有作者登录后可见**，别人打不开，这是正常的。
- 预览通过 → 提交审核 → **审核通过并确认发布后**，平台才会生成正式的公网访问链接。
- 审核期间别人看到的是占位状态，不是你的作品出了问题。

## 二、调用模型：硅基流动免费模型

作品默认用内置的话术陪聊，不花钱、不联网也能完整体验。如果想让模型临场组织语言，用硅基流动的免费开源模型：

1. **注册一次**：打开 <https://cloud.siliconflow.cn/>，用手机号注册登录（免费模型通常需要实名认证）。
2. **申请一个 Key**：到 <https://cloud.siliconflow.cn/me/account/ak> 创建 API Key，复制备用。
3. **选免费模型**：在 <https://siliconflow.cn/pricing> 看哪些模型标价为 0。免费是**活动规则、会变动**，以价格页实时显示为准，不要把某个模型当成永久免费。
4. **在作品里接入**：点页面顶部的「接入模型」→ 三步引导 → 粘贴 Key → 选模型 → 点「就用它」。

> 本项目预置了几个曾标价 0 的对话模型作为快捷项（GLM-4-9B、GLM-Z1-9B、星辰 29B、混元 7B），也允许手填任意模型 ID。

### 密钥机制（必须如实向用户说明）

| 项 | 机制 |
|---|---|
| 存在哪 | 仅当前页面 JS 内存 |
| 刷新 / 关页 | 立即消失 |
| 本地存储 | 不写 localStorage / sessionStorage / IndexedDB / Cookie |
| 网络 | 只发往硅基流动官方接口 `api.siliconflow.cn`，作为鉴权头，不经中间方 |
| 源码 / 仓库 / 上传包 | 不含密钥 |
| 他人 | 看不到、拿不到；每人填自己的 Key |

**Agent 与开发者不得读取、记录、展示用户填入的 Key。**
