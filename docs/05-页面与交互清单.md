# 05 页面与交互清单

> 口径：当前运行的 React 19 + Vite 原型（`src/App.tsx` 三空间 + `src/components/*`），文案统一取自 `src/copy.ts`。
> 本文只记录**可点击 / 可切换**的动作：按钮、可点卡片、Tab、折叠入口、下拉、可拖拽对象、开关。纯展示文案、静态科普段落、提示条（Toast）不列入点击项，单列在文末。
> 标注：**P0** = 本期交付范围；**范围外** = 保留可体验，未纳入本期验收。

## 0. 全局约定

| 层级 | 控件 | 点击后 | 备注 |
|---|---|---|---|
| 全局 | 弹窗右上 `×` / 「先收起来」 | 关闭弹窗，回到原页面 | 所有弹窗统一外壳，无遮罩穿透 |
| 全局 | 确认类弹窗「确认 / 再想想」 | 执行 / 取消 | 删除类操作两层确认 |
| 全局 | 提示条 | 不可点击 | 只做告知（复制成功、置顶已满、备份导出等） |
| 键盘 | `Enter` / `Shift + Enter` | 发送 / 换行 | 仅回音谷输入框 |
| 键盘 | `Esc` | 关弹窗、退出标签/石子编辑 | 编辑类输入框 |
| 拖拽 | 周表格任务卡、溪边石子 | 拖到别的日子 / 拖到别的石子前 | 开启「减少动态效果」时禁用 |

响应式差异（≤ 979px）：

- 头部隐藏「静一下心」文字入口、「演练」入口、静一下心页内「← 回到山谷 / 设置」——由底部 Tab 与页内控件补位。
- 回音谷三入口、向导、计划面板、周表格均改为单列竖排，控件文案不变。

## 附 C · 动效接线清单（ReactBits 克制版）

改动都在「视觉与手感」层，不改任何交互含义：原来能点的位置、原来的二次确认流程一个都没少。

| 组件 | 接在哪 | 起到什么作用 | 退出条件 |
| --- | --- | --- | --- |
| WarmTooltip | 页头六处弱入口：季节切换、减少动态、接入模型、路演、设置、静一下心 | 悬停 400ms 才出现一句短提示，移开 300ms 内滑到下一个不重新等 | 触摸设备不出；键盘聚焦会出 |
| SplitText | 山谷标题（「山谷在听」/「山谷里的回音」）、静一下心标题、向导提问句、回音空态 | 字号小、行数少的地方做一次「浮起/模糊进场」，读完就不再动 | `减少动态效果` 打开时完全不拆字 |
| JellyRadio | 向导每步选项、这一件的「大概花多久」、静一下心筛选、石子标签筛选、设置存储方式、模型四选一 | 单选从「呆板 chip」换成带一点回弹的胶囊，选中时邻居轻微让位 | 步进式交互（如状态五连、chips 可多选的第 3 步）保持原按钮 |
| FlipCard | 设置页「边界与备份」小卡 | 正面一句话，翻过来是三条边界说明；原来那段长说明没有删，只是收纳到背面 | 只用点击/拖动翻面，不做循环 |
| SwipeRow | 回音列表单条回音 | 左滑露出「归档 / 让回音消散」抽屉；**fullSwipe 永久关闭**，一滑到底不会直接删 | 拖动超过 8px 会吞掉抬手那一下的点击，避免误开聆听弹窗 |
| Shredder | 让回音消散 / 一键清空山谷 / 全部回音消散 | 先弹确认，确认后纸条下落散开，播完才真正删库 | `减少动态效果` 时 240ms 直接完成 |

### 刻意没接的地方

- 石子列表不加 SwipeRow：卡片本身要竖直拖拽排序、整块可点展开，横向滑动会和这两个手势互相抢。
- 状态五连（已安排 / 进行中 / 想缓一缓 / 改天再来 / 已放下）保持原按钮：选「已放下」要先问一句再摊平，弹性胶囊会把这个确认步骤藏掉。

## 附 D · 手机端布局（≤560px / ≤420px）

只动排版与尺寸，不动任何交互与文案。390 × 844 与 360 × 780 两档都逐页看过。

| 位置 | 手机上的做法 | 为什么 |
| --- | --- | --- |
| 页头 | 品牌占第一行，「了解更多」固定在第一行右侧；六个入口收成一条可横滑的带子，字号与季节圆点缩一档 | 原来会折成三行、最后一行只剩一个「了解更多」；360 宽时「设置」还能留在首屏 |
| 边界说明 | 展开后改成贴底浮层（左右 12px、底部让开底部导航） | 横滑带子会裁掉原本绝对定位的小卡 |
| 面板头 | 标题吃满一行，操作链接折到第二行 | 「这周走到这里了」原来被右侧操作挤成「了」单独一行 |
| 节点详情 | 标签 11px、内容 13px，撑满单列，行距松开 | 手机上原来的 10 / 12.5px 两列挤得难读 |
| 一周表 | 日期列 52px（小屏 46px）、行高 44px | 任务名有更多横向余量，行高够手指点 |
| 底部导航 | 左右各 12px、等分三格 | 小屏不横溢出，三个 Tab 都好点 |
| 弹性胶囊 | 最小高度 32px | 触摸目标不低于 32px |
| 悬停提示 | 只有键盘聚焦才弹；触屏点一下不再弹气泡 | 原来点「设置」会顺手弹出一句提示 |

小屏（≤420px）再收一档：品牌副标题隐藏、季节圆点 20px、工具文字 10.5px。

复检方式：`.shots/手机视口检查.html` 里放了 390 与 360 两个 iframe，开发服务起在 5179 后直接打开即可看两档同屏。
