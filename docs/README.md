## 技术栈

Vue3 + FastAPI + SQLite + OpenAI 兼容 LLM；用户名密码注册 + JWT。

## 核心机制

- 双空间隔离：`valley`（情绪/感悟/闲聊）与 `path`（计划/任务）互不越界。
- 回音：用户确认后才保存原话+时间戳；可手动指令强制保存；删除不可恢复。
- 镜像回音：自我否定时引导用户写"写给自己的回音"，成对保存。
- 复盘：仅用户主动触发；旧回音纯文本念回 + 双线并排，不做解读。
- 红线：不搜题、不诊断、不偷存、不推送、不贴标签、无积分（详见 01）。
